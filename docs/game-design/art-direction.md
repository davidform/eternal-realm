# Eternal Realm 美術設計規範

本文件定義 Eternal Realm 的視覺語言與遊戲資產規格。目標是在瀏覽器中維持清楚的戰鬥辨識度，同時建立具有暗黑奇幻氣氛、但不壓暗到看不清互動物件的 16-bit 風格世界。

## 視覺定位

整體採用「16-bit 靈感像素藝術加現代光影」。造型使用清楚的像素群與輪廓，不模仿任何既有遊戲；光影可以細緻，但角色、怪物、掉落物和危險範圍必須比背景更醒目。

三個視覺支柱：

- 清楚輪廓：縮小到遊戲尺寸後仍能辨認職業與怪物。
- 古老金光：永恆碎片、Boss Treasure 和關鍵劇情使用一致的古金色。
- 黑暗但可讀：環境使用深綠與靛藍，互動物件使用較高明度與色彩純度。

## 四職業造型

### Knight

藍鋼板甲、象牙披巾、古金邊框與圓盾構成寬而穩定的輪廓。移動時重量感明顯，攻擊特效短而厚，不使用過多拖尾。

### Elf

森林綠披風、銀金長髮、長弓和輕革甲構成高而流動的輪廓。箭矢與風系效果使用纖細曲線，避免和 Mage 的圓形法術混淆。

### Mage

深靛藍長袍、紫色層次與琥珀法杖核心構成三角形輪廓。法術以圓形符文、星點和金色核心呈現，身體比例不因長袍而失去可讀性。

### Dark Elf

黑曜皮甲、洋紅圍巾、銀紫頭髮與雙曲刃構成尖銳的斜線輪廓。特效使用短促洋紅殘影，與 Elf 的綠色遠程軌跡區分。

## 第一章怪物造型

- Meadow Slime：翡翠半透明身體與琥珀核心。圓形輪廓表示最低威脅。
- Meadow Goblin：橄欖綠皮膚、拼補皮甲和缺口砍刀。向前傾的姿勢強調侵略性。
- Grey Wolf：銀灰長毛與青綠眼睛。水平輪廓和較快移動速度互相呼應。
- Goblin King Gorvak：鐵冠、深紅毛皮和巨大砍刀形成寬大型輪廓；胸甲中的古金碎片是視覺焦點。

## Green Meadow 環境

Green Meadow 由月光草地、苔石、破敗遺跡和遠方 Goblin 木牆構成。中央路徑自然引導玩家往右方營地前進。Boss 區加入暖色火光與褐紅地面，使玩家在小地圖缺席時仍能感覺自己進入危險區域。

永恆之門在遠景中使用垂直金光和破裂石環。它必須比 Goblin Camp 更遠、更巨大，暗示第一章 Boss 只是長期主線的入口。

## UI 規範

- 面板使用半透明深靛藍，不遮蔽主要遊戲畫面。
- 標題使用襯線字呈現古典感；數值和操作提示使用清楚的無襯線字。
- HP 固定使用紅色，EXP 使用藍色，Boss 使用紅橙漸層。
- Boss Treasure 使用橘金色並持續浮動；普通 Gold 使用黃色，裝備使用藍色。
- 劇情 Chronicle 每次只顯示一個標題與一個短段落。

## 遊戲資產規格

- 角色和怪物使用透明 PNG。
- 目前概念資產為高解析度像素風 cutout，由 Phaser 縮放並使用 nearest filter。
- 後續動畫版採固定方向 sprite sheet，優先製作 Idle、Walk、Basic Attack、Hit、Death。
- 同一類資產維持一致視角、光源與透明邊界。
- 不將文字烘焙進場景或角色圖片，確保多語系與 UI 可調整。

## 圖像生成規格

本批資產以內建 imagegen 生成。共同提示規格為：原創 16-bit 靈感像素藝術、三分之四俯視角、清楚像素群、遊戲可用輪廓、無文字、無商標、無浮水印。角色與怪物要求真正透明背景；Green Meadow 主視覺要求寬幅構圖、中央道路、月光草地、Goblin 營地與遠方發光的破裂永恆之門。

後續生成新資產時必須沿用此視角、輪廓與色彩規則，不能只以「像素風」作為唯一風格描述。
